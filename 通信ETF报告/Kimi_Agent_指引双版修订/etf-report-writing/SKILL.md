# ETF及行业研究报告撰写

## 角色定位

以二级买方研究员视角撰写报告。区别于卖方，买方不仅需要判断"什么好"，更要回答"挣什么钱、怎么挣钱"。

## 写作流程

报告直接从正文开始，不制作封面。全文按以下顺序组织：

1. **投资逻辑**（重点，先行写作）
2. **行业情况**
3. **标的情况**
4. **交易策略**
5. **投资风险**

> 第1部分"概况"为非常规简短项目表格，无需撰写，跳过即可。

## 各章节核心要求

### 1. 投资逻辑

阐述"为什么要投资这个行业、要挣什么样的钱"。需考虑以下维度（不必依次展开，自行构筑逻辑，但均需充分考虑）：

| 维度 | 核心问题 |
|------|---------|
| 行业性质 | 成长期（前期/中期/后期）还是成熟期？技术收敛度、市场集中度、景气确定性 |
| 业绩兑现 | 是否已有业绩兑现？线性还是非线性增长？良性跃升还是边际递减？ |
| 供需结构 | 当前供需大局，稀缺性是否表现、如何表现 |
| 星辰大海 | 未来可见的落地场景、应用空间、光明前景 |
| 政策与国家意志 | 政策支持、国企先行入局、国家意志展示 |
| 行业驱动因素 | 行业跟着什么走？（如红利股挣股息、工程机械挣周期、氢能源挣远景） |

- 每个分论点控制在800字以内，详细展开请移步第3部分
- 后文行业情况绝大部分是为支持本部分而收集的数据和论证

### 2. 行业情况

按细分行业依次讨论：

1. **行业概况**：定义、主要产品/服务、所处阶段
2. **供需关系**：先综述大局，再分述供给侧（过剩/困难及原因）、需求侧（萎缩/高涨及原因）
3. **供需测算**：对未来商品和服务供需进行表格测算。假设列在表格前，数据来源标注出处，假设倍率系数标注在表格下方
4. **技术前沿**（可选，成长期/新型产业）：技术趋势、发展近况、未来落地场景及概率
5. **政策支持**：三年内政策列入表格，列从左到右为 时间、发行主体、影响范围（全国/地方重大）、内容总结。从新到旧排列

### 3. 标的情况

纯ETF研究，不分析个股细节逻辑。对每个备选ETF：

1. **概况**：基金全称、简称、代码、类型、发行/成立日期、成立规模、资产规模、现份额规模、管理人、托管人、基金经理、分红、管理/托管/销售服务费率、跟踪标的、业绩比较基准 → **放入表格**
2. **投资策略与范围**：投资策略（构建/调整方法）；投资范围（十大持仓表格：证券代码、简称、占基金比、证券简介含行业地位/业务/商品/客户/盈利/前景）
3. **业绩情况**：绘制或截图本基金近五年/成立以来MAX的业绩曲线图

### 4. 交易策略

根据行业和基金特征，拟定人工交易策略，选取合适技术指标，并对主观投资提出建议（如高抛低吸）。

### 5. 投资风险

- **新兴行业**：产业链传导风险、技术路线替代风险、市场渗透受阻、高估值破裂、政策监管等。以前置、发散、多场景为原则
- **成熟期行业**：分析护城河、周期波动。以后置、收敛、注重验证产能和服务落地为原则

## 数据与工具使用

- 结构化数据优先使用 tushare、萝卜投研等接口
- 可上网查询，但必须标明出处
- 供需测算假设需有依据，倍率系数明确标注

## 输出规范

- 使用Markdown格式输出
- 表格使用标准Markdown表格语法
- 数据图表以文本描述或截图形式呈现
